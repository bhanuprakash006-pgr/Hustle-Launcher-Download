# Hustle Launcher

### Focus can't be negotiated.

Hustle Launcher is an Android launcher designed to help you take control of your phone, reduce distractions, and build a more intentional digital experience.

## Features

- **Minimal Launcher:** A clean, distraction-free home screen.
- **App Drawer:** Access and organize your installed applications.
- **Focus Mode:** Restrict selected applications during focus sessions.
- **Focus Protection:** Help prevent access to restricted applications.
- **Screen Time:** View your device usage and application-level statistics.
- **Built-in Browser:** Browse the web with selected website and download restrictions.
- **Hustle Settings:** Manage launcher preferences and application features.

## Installation

1. Download the latest Hustle Launcher APK.
2. Open the downloaded APK on your Android device.
3. Allow installation from the source if Android requests permission.
4. Complete the installation.
5. Set Hustle Launcher as your default Home app when prompted.

## Requirements

- Android 8.0 (API 26) or later.
- Certain features require additional Android permissions.

## Permissions

Hustle Launcher may request:

- **Installed Application Access:** To display and organize installed applications.
- **Usage Access:** To calculate screen-time statistics.
- **Accessibility Service:** To enforce Focus Mode and application restrictions.
- **Internet Access:** To support the built-in browser.

You can review the permissions and their purposes before enabling them.
